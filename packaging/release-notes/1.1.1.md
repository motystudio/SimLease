# SimBar 1.1.1

After updating, open the gear menu in SimBar and choose **Install everything** to update the `sim-lease` script. A new window now shows each step as it completes.

## Changed

- The default device limits now follow your Mac's memory instead of a fixed 3 iOS and 2 Android. The setup assistant and Settings show the suggestion, and a value you set yourself always wins.

## Added

- Installing from the gear menu shows each step, with a check mark once it is done and the error of a step that failed.
- `acquire --name` makes another simulator when all those with that name are taken and a slot is free or can be freed. It starts empty, and it stays available for later sessions.

## Fixed

- Opening Settings no longer crashes SimBar.
- `sim-lease version` now reports the right version.
